# Zombie Wiki

A personal world-building wiki for a post-apocalyptic zombie world, built with
Next.js.

Most of the code in this project was generated by AI primarily  Copilot

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the wiki. Use
`npm run build` to create a production build and `npm start` to serve it.
